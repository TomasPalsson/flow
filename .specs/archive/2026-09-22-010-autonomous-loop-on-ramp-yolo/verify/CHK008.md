# CHK008 — one real unattended --yolo run reaches a draft PR

Pass = all three are true:
- [ ] a draft PR exists on the throwaway repo
- [ ] no question/permission prompt was asked during the run
- [ ] the final report names the cap that ended it (or says it finished)

## How to run
    gh repo create <you>/yolo-throwaway --private --clone --add-readme
    cd yolo-throwaway
    claude    # then type:
    /flow:loop "a CLI that prints word counts for a file, with tests" --yolo

## Evidence to drop in this folder
- pr-url.txt        — `gh pr view --json url,isDraft > pr-url.txt`
- report.md         — the loop's final report (copy from terminal or `flow loop status`)
- prompts.txt       — one line: "no prompts seen" (or what was asked)
