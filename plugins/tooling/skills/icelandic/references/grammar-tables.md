# Icelandic Grammar Reference Tables

## Noun Declension Paradigms

### Strong Masculine — A-class: hestur (horse)

| | Sg. indef. | Sg. def. | Pl. indef. | Pl. def. |
|--|--|--|--|--|
| Nom | hestur | hesturinn | hestar | hestarnir |
| Acc | hest | hestinn | hesta | hestana |
| Dat | hesti | hestinum | hestum | hestunum |
| Gen | hests | hestsins | hesta | hestanna |

### Strong Masculine — u-stem with umlaut: sonur (son)

| | Sg. | Pl. |
|--|--|--|
| Nom | sonur | synir |
| Acc | son | syni |
| Dat | syni | sonum |
| Gen | sonar | sona |

Trap: dat.sg shows umlaut (syni) but dat.pl does NOT (sonum).

### Irregular: maður (man/person)

|--|--|--|
| Nom | maður | menn |

### Root noun: fótur (foot)

| | Sg. | Pl. |
|--|--|--|
| Nom | fótur | fætur |
| Acc | fót | fætur |
| Dat | fæti | fótum |
| Gen | fótar | fóta |

Trap: Plural nom/acc uses æ but dat.pl returns to ó (fótum, NOT *fætum).

### Kinship r-stems: faðir (father)

| | Sg. | Pl. |
|--|--|--|
| Nom | faðir | feður |
| Acc | föður | feður |
| Dat | föður | feðrum |
| Gen | föður | feðra |

Same pattern: móðir, bróðir, systir (systur in oblique sg and nom/acc pl; dat.pl systrum, gen.pl systra).

### Strong Feminine — bók (book, root noun with umlaut)

| | Sg. | Pl. |
|--|--|--|
| Nom | bók | bækur |
| Acc | bók | bækur |
| Dat | bók | bókum |
| Gen | bókar | bóka |

ó→æ in pl nom/acc; ó retained in dat.pl. Gen.pl bóka (NOT *bæka).

### Strong Feminine — -ing class: kenning

|--|--|--|
| Nom | kenning | kenningar |
| Acc | kenningu | kenningar |
| Dat | kenningu | kenningum |
| Gen | kenningar | kenninga |

Acc/dat sg add -u.

### Strong Neuter — with u-mutation: barn (child)

| | Sg. | Pl. |
|--|--|--|
| Nom | barn | börn |
| Acc | barn | börn |
| Dat | barni | börnum |
| Gen | barns | barna |

Same pattern: land→lönd, glas→glös, fat→föt.

### Weak Masculine: tími (time)

|--|--|--|
| Nom | tími | tímar |
| Acc | tíma | tíma |
| Dat | tíma | tímum |
| Gen | tíma | tíma |

### Weak Feminine: tunga (tongue)

| | Sg. | Pl. |
|--|--|--|
| Nom | tunga | tungur |
| Acc | tungu | tungur |
| Dat | tungu | tungum |

## Gender Traps

These nouns are commonly assigned the wrong gender:
- hjarta (heart) — NEUTER (not feminine despite -a ending)
- eyra (ear) — NEUTER
- lunga (lung) — NEUTER
- norður, suður, austur, vestur — all NEUTER (despite -ur ending)
- fólk (people) — NEUTER SINGULAR (fólk er, NOT *fólk eru)
- kaffi (coffee) — NEUTER
- epli (apple) — NEUTER
- -ing nouns (kenning, hreyfing, spurning) — always FEMININE
- -un nouns (verslun, þjálfun) — always FEMININE

## Preposition Case Government

### Accusative only
um (about), kringum (around), umhverfis (around), gegnum (through)

### Dative only
frá (from), hjá (at/with), af (off), að (toward), móti (against), úr (out of)

### Genitive only
til (to/of), milli (between), án (without), vegna (because of), meðal (among)

### Variable (ACC = motion, DAT = location)
- í: í bæinn (acc, into) vs. í bænum (dat, in)
- á: á borðið (acc, onto) vs. á borðinu (dat, on)
- yfir: yfir brúna (acc, across) vs. yfir brúnni (dat, above)
- undir: undir borðið (acc, under-motion) vs. undir borðinu (dat, under-static)

### Semantically variable
- fyrir: acc = for (benefit); dat = in front of, ago (fyrir tveimur árum)
- með: acc = bring along; dat = together with
- eftir: acc = after in time, by (author): eftir stríðið, bók eftir hann; dat = along, following, waiting for: eftir veginum, bíða eftir honum
- við: acc = by, against, toward: við gluggann; dat = receiving, in response to: taka við því, bregðast við því

## Strong Verb Ablaut Classes

### Class 1: í ~ ei ~ i ~ i(ð)
bíta (beit, bitum, bitið), rísa (reis, risum, risið), skína (skein, skinum, skinið)

### Class 2: jó/jú/ú ~ au ~ u ~ o(ið)
bjóða (bauð, buðum, boðið), ljúga (laug, lugum, logið), sjóða (sauð, suðum, soðið)
Present singular: jó/jú/ú → ý (ég býð, ég lýg, hann lýgur)

### Class 3: e/i+CC ~ a ~ u ~ u(ð)
finna (fann, fundum, fundið), brenna (brann, brunnum, brunnið), vinna (vann, unnum, unnið)

### Class 4: e/i+C ~ a ~ á ~ o(ið)
bera (bar, bárum, borið), stela (stal, stálum, stolið)
koma (kom, komum, komið) — irregular, past pl. leveled

### Class 5: e/i+C ~ a ~ á ~ e(ið)
gefa (gaf, gáfum, gefið), lesa (las, lásum, lesið), sjá (sá, sáum, séð), vera (var, vorum, verið)

### Class 6: a ~ ó ~ ó ~ a(ið)
fara (fór, fórum, farið), standa (stóð, stóðum, staðið), taka (tók, tókum, tekið)
Present singular: a→e (ég fer, þú ferð, hann fer; ég tek, hann tekur) — fara 3sg = fer, NOT *far

### Class 7: mixed ablaut
- 7a: heita (hét, hétum, heitið), leika (lék, lékum, leikið)
- 7b: auka (jók, jókum, aukið), hlaupa (hljóp, hljópum, hlaupið)
- 7c: falla (féll, féllum, fallið), halda (hélt, héldum, haldið), ganga (gekk, gengum, gengið)
- 7d (ri-verbs): gróa (greri, grerum, gróið), snúa (sneri, snerum, snúið)

halda is class 7 (hélt), NOT class 6.

## Adjective Declension

### Strong (indefinite) — stór (big)

| | M | F | N |
|--|--|--|--|
| Nom.sg | stór | stór | stór-t |
| Acc.sg | stór-an | stór-a | stór-t |
| Dat.sg | stór-um | stór-ri | stór-u |
| Gen.sg | stór-s | stór-rar | stór-s |
| Nom.pl | stór-ir | stór-ar | stór |
| Acc.pl | stór-a | stór-ar | stór |
| Dat.pl | stór-um | stór-um | stór-um |
| Gen.pl | stór-ra | stór-ra | stór-ra |

### Weak (definite) — stór

| | M | F | N |
|--|--|--|--|
| Nom.sg | stór-i | stór-a | stór-a |
| All other | stór-a | stór-u | stór-a |
| All pl | stór-u | stór-u | stór-u |

Trigger rule: WEAK when noun phrase contains definite article, demonstrative, or possessive. STRONG otherwise. Predicative adjectives are strong, except comparatives, which are always weak (hún er stærri).

## Verb-Governed Object Cases (Non-Accusative Objects)

### Dative objects
hjálpa (help): hjálpa honum (NOT *hann)
gleyma (forget): gleyma henni (NOT *hana)
þakka (thank): þakka honum
trúa (believe): trúa honum
lýsa (describe): lýsa henni
þjóna (serve): þjóna honum
svara (answer): svara honum

### Genitive objects
leita (search for): leita hans
njóta (enjoy): njóta þess
gæta (guard/watch): gæta barna
vitja (visit): vitja hennar
