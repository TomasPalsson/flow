## Word Formation — Productive Suffixes

| Suffix | Function | Example |
|--------|----------|---------|
| -legur | adj-forming (-ful, -ous, -ly) | náttúrulegur (natural), skaðlegur (harmful) |
| -semi | abstract noun (-ness) | skynsemi (reason), frjósemi (fertility) |
| -skapur | abstract noun (-ship, -hood) | skáldskapur (fiction), vinskapur (friendship) |
| -un | verbal noun (-tion, -ing) | þróun (development), menntun (education) |
| -andi | agent noun / participle | nemandi (student), lesandi (reader) |
| -dómur | abstract noun (-dom) | vísdómur (wisdom), sjúkdómur (disease) |
| -hyggja | ideology suffix (-ism) | þjóðernishyggja (nationalism), frjálshyggja (liberalism) |
| -erni | abstract quality | þjóðerni (nationality), víðerni (wilderness) |

## Word Formation — Productive Prefixes

| Prefix | Meaning | Example |
|--------|---------|---------|
| ó- | negation (un-, non-) | ófriður (war, lit. un-peace), óheppni (bad luck) |
| mis- | error (mis-) | misskilningur (misunderstanding), misnotkun (misuse) |
| for- | before, intensification | forrit (program), formaður (chairman) |
| sam- | co-, together | samfélag (society), samtal (conversation) |
| and- | anti-, against | andstæða (opposite), andheiti (antonym) |
| auð- | easily | auðvitað (of course), auðsýnn (obvious) |
| aðal- | main, chief | aðalbygging (main building), aðalpersóna (protagonist) |

## Commonly Confused Words

| Word | Meaning | NOT |
|------|---------|-----|
| giftur/gift | married | NOT gift/present (that's gjöf) or poison (eitur) |
| ský | cloud | NOT sky (that's himinn or loft) |
| skáldskapur | fiction (broadly) | NOT just poetry |
| loft | air, sky, ceiling, attic | Broader than English "loft" |
| mál | language / matter / time / measurement | Highly polysemous |
| hætta | danger (noun) / to stop (verb) | Dual meaning |
| nú (formal) | now | núna (colloquial) |
